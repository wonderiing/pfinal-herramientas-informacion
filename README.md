# FixIt Solutions - Helpdesk Support Platform

## Contexto de la Organización
FixIt Solutions provee una aplicación web ligera para el registro, seguimiento y comentarios de incidencias técnicas reportadas por clientes. Ante el crecimiento de reportes de errores y solicitudes de mejora, el equipo de ingeniería requiere una auditoría preliminar de seguridad para revisar el repositorio antes de lanzar su próxima actualización.

## Objetivo de la Fase 1
Los alumnos deben realizar un análisis preliminar y un plan de auditoría **sin ejecutar herramientas de escaneo en esta etapa**, inspeccionando la estructura del proyecto y los componentes para identificar los riesgos esperados.
